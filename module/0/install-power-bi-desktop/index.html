Installing Power BI Desktop

In about 12 minutes you will be able to have Power BI Desktop installed and opening on your own computer.
Dalam sekitar 12 menit kamu bakal bisa sudah menginstal Power BI Desktop dan bisa membukanya di komputermu sendiri.

⏱ 12 min 📊 Difficulty: Easy ✅ You need first: A Windows PC or laptop.
No download needed. This is a reading lesson — just follow along. Nggak perlu download apa-apa, cukup dibaca.

Power BI Desktop only runs on Windows. If you use a Mac, see the note at the bottom before you start. Installing is free and takes about ten minutes.

Power BI Desktop cuma jalan di Windows. Kalau kamu pakai Mac, baca catatan di bawah dulu sebelum mulai. Instalnya gratis dan makan waktu sekitar sepuluh menit.

  1. Open the Microsoft Store on your Windows computer. Click the Start button and type Microsoft Store, then open it.

    Buka Microsoft Store di komputer Windows kamu. Klik tombol Start lalu ketik Microsoft Store, terus buka.

    Menu path: Start ▸ Microsoft Store

  2. Search for Power BI Desktop and click the result published by Microsoft Corporation. Publisher matters — pick the official one.

    Cari Power BI Desktop lalu klik hasil yang diterbitkan oleh Microsoft Corporation. Penerbit itu penting — pilih yang resmi.

  3. Click the blue Get button and wait for it to download and install. This can take a few minutes on a slower connection.

    Klik tombol biru Get lalu tunggu proses download dan instalnya. Bisa beberapa menit kalau koneksimu lambat.

  4. When it finishes, open Power BI Desktop from the Start menu. The first time, a yellow welcome screen appears. Close it with the × in its corner.

    Setelah selesai, buka Power BI Desktop dari Start menu. Pertama kali dibuka, muncul layar sambutan kuning. Tutup dengan tombol × di pojoknya.

    Menu path: Start ▸ Power BI Desktop

✓ Checkpoint — you should now see this

You should now see the main Power BI Desktop window: a ribbon of tabs along the top, a big empty white area in the middle, and panes down the right side.

Sekarang kamu harusnya melihat jendela utama Power BI Desktop: deretan tab (ribbon) di atas, area putih kosong besar di tengah, dan panel-panel di sisi kanan.

Why this matters / Kenapa ini penting

Getting the real tool open on your own machine is the step most people skip by only watching videos. You learn Power BI by clicking, not by watching.

Membuka tool aslinya di komputer sendiri adalah langkah yang paling sering dilewati orang yang cuma nonton video. Power BI dipelajari dengan mengklik, bukan dengan menonton.

Common mistakes / Kesalahan yang sering terjadi

  • Installing on a Mac / Menginstal di Mac
    Power BI Desktop is Windows-only. On a Mac you need Windows through Parallels, Boot Camp, or a cloud PC. There is no Mac version, and there won't be one. Power BI Desktop cuma untuk Windows. Di Mac kamu butuh Windows lewat Parallels, Boot Camp, atau cloud PC. Nggak ada versi Mac, dan memang nggak akan ada.
  • Downloading a random installer from a website / Download installer sembarangan dari website
    Use the Microsoft Store or Microsoft's official download page only. Other sites may bundle unwanted software. Pakai Microsoft Store atau halaman download resmi Microsoft saja. Situs lain bisa menyelipkan software yang nggak kamu mau.
