Import your first file

In about 12 minutes you will be able to load a CSV file into Power BI and see its rows appear.
Dalam sekitar 12 menit kamu bakal bisa memuat file CSV ke Power BI dan melihat baris-barisnya muncul.

⏱ 12 min 📊 Difficulty: Easy ✅ You need first: Power BI Desktop open. Download the dataset below.
Practice dataset: Coffee shop sales 90 rows of pretend sales from a small coffee shop. / 90 baris penjualan pura-pura dari kedai kopi kecil.
⬇ Download dataset

Time to bring real data in. Download the coffee shop file above, remember where it saves (usually your Downloads folder), and follow along.

Saatnya masukin data asli. Download file kedai kopi di atas, ingat di mana dia tersimpan (biasanya folder Downloads), lalu ikuti langkahnya.

  1. On the Home tab of the ribbon, click Get data. A menu drops down.

    Di tab Home pada ribbon, klik Get data. Menu akan turun.

    Menu path: Home ▸ Get data

  2. Choose Text/CSV from the list. If you don't see it, click More… and search for it.

    Pilih Text/CSV dari daftar. Kalau nggak kelihatan, klik More… lalu cari.

    Menu path: Home ▸ Get data ▸ Text/CSV

  3. A file browser opens. Find coffee-sales.csv in your Downloads folder, click it once, then click Open.

    Jendela pencari file terbuka. Temukan coffee-sales.csv di folder Downloads, klik sekali, lalu klik Open.

  4. A preview window appears showing your table. Look it over — this is your data. Don't touch the settings at the top yet.

    Muncul jendela pratinjau yang menampilkan tabelmu. Perhatikan dulu — ini datamu. Jangan sentuh pengaturan di atas dulu.

  5. Click the blue Load button at the bottom right. Power BI pulls the data in.

    Klik tombol biru Load di kanan bawah. Power BI menarik datanya masuk.

✓ Checkpoint — you should now see this

In the Fields pane on the right you should now see coffee-sales with a small triangle you can expand to reveal the column names.

Di panel Fields sebelah kanan sekarang harusnya muncul coffee-sales dengan segitiga kecil yang bisa kamu buka untuk memperlihatkan nama-nama kolom.

Why this matters / Kenapa ini penting

This is the single most-used action in all of Power BI. You will click Get data at the start of every project for the rest of your career. Get comfortable with it now.

Ini aksi yang paling sering dipakai di seluruh Power BI. Kamu bakal klik Get data di awal tiap proyek sepanjang kariermu. Nyamanin diri sama ini sekarang.

Common mistakes / Kesalahan yang sering terjadi

  • Clicking Transform data instead of Load / Mengklik Transform data padahal maunya Load
    Both buttons are on the preview screen. For now click Load. Transform opens a whole editor you meet in Module 2. Kedua tombol ada di layar pratinjau. Untuk sekarang klik Load. Transform membuka editor lengkap yang kamu temui di Modul 2.
  • Losing track of where the file downloaded / Lupa di mana file ter-download
    If you can't find the file, check your browser's downloads list — it shows the exact folder. Kalau nggak nemu file-nya, cek daftar unduhan di browser — di situ ada folder persisnya.
