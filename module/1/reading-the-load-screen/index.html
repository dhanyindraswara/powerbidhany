Reading the load screen

In about 9 minutes you will be able to understand the two choices Power BI offers you on the import preview and pick correctly.Dalam sekitar 9 menit kamu bakal bisa memahami dua pilihan yang ditawarkan Power BI di pratinjau impor dan memilih dengan benar.

⏱ 9 minmenit DifficultyTingkat: EasyGampang You need firstButuh dulu: Lesson 1.2 finished, coffee-sales loaded.Pelajaran 1.2 selesai, coffee-sales sudah dimuat.
Practice datasetDataset latihan: Coffee shop sales The same file from the last lesson.File yang sama dari pelajaran sebelumnya.
⬇ Download dataset

That preview window had a couple of settings you skipped. Now let's look at them so they never confuse you.

Jendela pratinjau tadi punya beberapa pengaturan yang kamu lewati. Sekarang kita lihat supaya nggak pernah bikin bingung.

  1. Re-open the import: Home ▸ Get data ▸ Text/CSV, pick the coffee file again to reach the preview.

    Buka lagi impornya: Home ▸ Get data ▸ Text/CSV, pilih file kopi lagi untuk sampai ke pratinjau.

    Menu path: Home ▸ Get data ▸ Text/CSV

  2. Look at Delimiter at the top. A delimiter is the character that separates columns. For a CSV it should say Comma. Leave it.

    Lihat Delimiter di atas. Delimiter adalah karakter yang memisahkan kolom. Untuk CSV harusnya tertulis Comma. Biarkan.

  3. See the two buttons at the bottom: Load takes the data straight in. Transform data opens the cleaning editor first. Choose Load for clean files, Transform when data needs fixing.

    Lihat dua tombol di bawah: Load langsung memasukkan data. Transform data membuka editor pembersih dulu. Pilih Load untuk file yang rapi, Transform kalau data perlu diperbaiki.

  4. For this clean file, click Load. In the next module you will click Transform on purpose.

    Untuk file yang rapi ini, klik Load. Di modul berikutnya kamu bakal klik Transform dengan sengaja.

✓ Checkpoint — you should now see thisCheckpoint — sekarang kamu harusnya lihat ini

You can explain, in your own words, the difference between the Load button and the Transform data button.

Kamu bisa menjelaskan, dengan kata-katamu sendiri, beda tombol Load dan tombol Transform data.

Why this mattersKenapa ini penting

Every import ends on this screen. Knowing which button does what means you never accidentally skip cleaning, or accidentally get stuck in an editor you didn't want.

Setiap impor berakhir di layar ini. Tahu tombol mana melakukan apa berarti kamu nggak pernah nggak sengaja melewati pembersihan, atau nggak sengaja terjebak di editor yang nggak kamu mau.

Common mistakesKesalahan yang sering terjadi

  • Changing the delimiter when it was already rightMengubah delimiter padahal sudah benar
    If your columns look correct in the preview, don't touch the delimiter. Changing it can scramble the table.Kalau kolommu sudah kelihatan benar di pratinjau, jangan sentuh delimiter. Mengubahnya bisa mengacak tabel.
  • Loading the same file twiceMemuat file yang sama dua kali
    If you already loaded coffee-sales, loading again makes coffee-sales (2). Delete duplicates from the Fields pane by right-clicking.Kalau coffee-sales sudah dimuat, memuat lagi membuat coffee-sales (2). Hapus duplikatnya dari panel Fields dengan klik kanan.
