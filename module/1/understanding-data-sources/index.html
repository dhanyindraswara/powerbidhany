Where data comes from

In about 8 minutes you will be able to recognise the three data sources a beginner will actually use and know which one this course uses.
Dalam sekitar 8 menit kamu bakal bisa mengenali tiga sumber data yang benar-benar dipakai pemula dan tahu mana yang dipakai kursus ini.

⏱ 8 min 📊 Difficulty: Easy ✅ You need first: Module 0 finished.
No download needed. This is a reading lesson — just follow along. Nggak perlu download apa-apa, cukup dibaca.

Power BI can read data from over a hundred places. You need exactly three of them right now, and this course uses the simplest one.

Power BI bisa membaca data dari lebih dari seratus tempat. Kamu cuma butuh tiga sekarang, dan kursus ini pakai yang paling sederhana.

  1. Source one: an Excel file. A workbook ending in .xlsx. The most common starting point for office work.

    Sumber satu: file Excel. Workbook yang berakhiran .xlsx. Titik awal paling umum buat kerjaan kantor.

  2. Source two: a CSV file, ending in .csv. A plain, simple table. This is what we download in every lesson.

    Sumber dua: file CSV, berakhiran .csv. Tabel yang polos dan sederhana. Ini yang kita download di tiap pelajaran.

  3. Source three: a database. A big shared store of data at your company. You will meet these at work, but you do not need one to learn.

    Sumber tiga: database. Tempat penyimpanan data besar yang dipakai bersama di kantormu. Kamu bakal ketemu ini di kerjaan, tapi buat belajar kamu nggak butuh.

✓ Checkpoint — you should now see this

You know that this course uses CSV files, that they are just simple tables, and that every lesson gives you one to download.

Kamu tahu kursus ini pakai file CSV, bahwa itu cuma tabel sederhana, dan tiap pelajaran kasih satu buat kamu download.

Why this matters / Kenapa ini penting

Choosing the wrong source type is the number one reason a beginner's first import fails. Knowing you want "Text/CSV" removes that whole class of mistake.

Salah memilih jenis sumber adalah alasan nomor satu kenapa impor pertama pemula gagal. Tahu bahwa kamu mau "Text/CSV" menghilangkan seluruh jenis kesalahan itu.

Common mistakes / Kesalahan yang sering terjadi

  • Opening a CSV in Excel first and re-saving it / Membuka CSV di Excel dulu lalu menyimpan ulang
    You don't need to. Power BI reads the .csv directly. Re-saving can quietly change your data. Kamu nggak perlu. Power BI membaca .csv secara langsung. Menyimpan ulang bisa diam-diam mengubah datamu.
  • Thinking you need a database to start / Mengira kamu butuh database buat mulai
    You don't. A single small file is enough to learn every skill in this course. Nggak butuh. Satu file kecil sudah cukup buat belajar semua skill di kursus ini.
