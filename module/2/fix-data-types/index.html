Fix data types

In about 11 minutes you will be able to set a column to the correct type so numbers add up and dates sort properly.
Dalam sekitar 11 menit kamu bakal bisa mengatur kolom ke tipe yang benar supaya angka bisa dijumlah dan tanggal bisa diurutkan dengan benar.

⏱ 11 min 📊 Difficulty: Medium ✅ You need first: Columns and rows cleaned from the last lesson.
Practice dataset: Messy orders Continue with your cleaned file. / Lanjut dengan file yang sudah kamu bersihkan.
⬇ Download dataset

Every column has a data type. If a number column is set to text, Power BI won't add it up. Fixing types is quiet but essential.

Setiap kolom punya data type. Kalau kolom angka disetel sebagai teks, Power BI nggak akan menjumlahkannya. Memperbaiki tipe itu senyap tapi wajib.

  1. Look at the tiny icon on the left of each column header. ABC means text, 123 means whole number, a calendar means date.

    Lihat ikon kecil di kiri tiap header kolom. ABC berarti teks, 123 berarti bilangan bulat, kalender berarti tanggal.

  2. The Price column shows ABC (text) but holds numbers. Click its type icon.

    Kolom Price menampilkan ABC (teks) padahal isinya angka. Klik ikon tipenya.

  3. Choose Decimal Number from the list. The icon changes and the values line up to the right, which means they are now real numbers.

    Pilih Decimal Number dari daftar. Ikonnya berubah dan nilainya rata kanan, tandanya sekarang benar-benar angka.

    Menu path: Click type icon ▸ Decimal Number

  4. Do the same for Order Date: click its type icon and choose Date.

    Lakukan hal sama untuk Order Date: klik ikon tipenya dan pilih Date.

    Menu path: Click type icon ▸ Date

  5. If a box asks to "Replace current" or "Add new step", choose Replace current.

    Kalau ada kotak menanyakan "Replace current" atau "Add new step", pilih Replace current.

✓ Checkpoint — you should now see this

Price shows a decimal-number icon and Order Date shows a calendar icon. Numbers sit on the right, dates read as real dates.

Price menampilkan ikon angka desimal dan Order Date menampilkan ikon kalender. Angka berada di kanan, tanggal terbaca sebagai tanggal betulan.

Why this matters / Kenapa ini penting

The most common "my total is wrong" bug in Power BI is a number column stuck as text. Fix types early and you dodge hours of confusion later.

Bug "kok totalku salah" paling umum di Power BI adalah kolom angka yang nyangkut jadi teks. Perbaiki tipe sejak awal dan kamu terhindar dari berjam-jam kebingungan nanti.

Common mistakes / Kesalahan yang sering terjadi

  • Ignoring the little type icons entirely / Mengabaikan ikon tipe kecil itu sama sekali
    They are easy to miss but they control everything. Always glance at them after loading data. Gampang terlewat tapi mengontrol segalanya. Selalu lirik ikonnya setelah memuat data.
  • Setting a date to a number by accident / Menyetel tanggal jadi angka nggak sengaja
    Dates turn into big numbers like 45000. If that happens, undo the step and pick Date instead. Tanggal berubah jadi angka besar seperti 45000. Kalau itu terjadi, batalkan langkahnya dan pilih Date.
