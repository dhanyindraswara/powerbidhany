What Power Query is

In about 9 minutes you will be able to open the Power Query Editor and understand that it records your steps.Dalam sekitar 9 menit kamu bakal bisa membuka Power Query Editor dan paham bahwa dia merekam langkah-langkahmu.

⏱ 9 minmenit DifficultyTingkat: EasyGampang You need firstButuh dulu: Module 1 finished.Modul 1 sudah selesai.
Practice datasetDataset latihan: Messy orders 60 rows with blank cells, wrong types, and extra columns — deliberately messy.60 baris dengan sel kosong, tipe salah, dan kolom berlebih — sengaja dibikin berantakan.
⬇ Download dataset

Power Query is a room inside Power BI where you tidy data before it reaches your charts. Its superpower: it remembers every change as a step, so you can redo it on new data instantly.

Power Query adalah ruangan di dalam Power BI tempat kamu merapikan data sebelum sampai ke grafikmu. Kekuatannya: dia mengingat setiap perubahan sebagai langkah, jadi kamu bisa mengulanginya di data baru seketika.

  1. Download messy-orders.csv above. Then Home ▸ Get data ▸ Text/CSV and pick it. This time, click Transform data, not Load.

    Download messy-orders.csv di atas. Lalu Home ▸ Get data ▸ Text/CSV dan pilih file itu. Kali ini, klik Transform data, bukan Load.

    Menu path: Home ▸ Get data ▸ Text/CSV ▸ Transform data

  2. The Power Query Editor opens in a new window. It looks like Power BI but greener. Your data fills the middle.

    Power Query Editor terbuka di jendela baru. Tampilannya mirip Power BI tapi lebih hijau. Datamu mengisi bagian tengah.

  3. Look at the Applied Steps panel on the right. Power BI already added a few steps for you. Every future change adds another line here.

    Lihat panel Applied Steps di kanan. Power BI sudah menambah beberapa langkah untukmu. Setiap perubahan berikutnya menambah satu baris di sini.

✓ Checkpoint — you should now see thisCheckpoint — sekarang kamu harusnya lihat ini

You are inside the Power Query Editor, you can see the messy data, and you can find the Applied Steps list on the right.

Kamu sudah di dalam Power Query Editor, bisa melihat data berantakannya, dan bisa menemukan daftar Applied Steps di kanan.

Why this mattersKenapa ini penting

In real jobs, the same messy report lands on your desk every month. Because Power Query records steps, you clean it once and replay the recipe forever. That is why it exists.

Di dunia kerja, laporan berantakan yang sama mendarat di mejamu tiap bulan. Karena Power Query merekam langkah, kamu membersihkannya sekali lalu memutar ulang resepnya selamanya. Itu alasan dia ada.

Common mistakesKesalahan yang sering terjadi

  • Closing the editor with the X and losing stepsMenutup editor dengan X dan kehilangan langkah
    Use Home ▸ Close & Apply to save your work. The window X can discard it.Pakai Home ▸ Close & Apply untuk menyimpan kerjaanmu. Tombol X pada jendela bisa membuangnya.
  • Thinking Power Query changes the original fileMengira Power Query mengubah file aslinya
    It never touches your CSV. All cleaning happens inside Power BI only.Dia nggak pernah menyentuh file CSV-mu. Semua pembersihan terjadi di dalam Power BI saja.
