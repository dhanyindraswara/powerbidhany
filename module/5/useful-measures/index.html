Count and average

In about 12 minutes you will be able to write a count of orders and an average sale using the same pattern.
Dalam sekitar 12 menit kamu bakal bisa menulis jumlah order dan rata-rata penjualan pakai pola yang sama.

⏱ 12 min 📊 Difficulty: Medium ✅ You need first: Total Sales measure written.
Practice dataset: Sales and products Continue in the same file. / Lanjut di file yang sama.
⬇ Download dataset

You know the shape now: Name = FUNCTION(Table[Column]). Swap SUM for COUNT or AVERAGE and you have two more measures in minutes.

Kamu sudah tahu bentuknya: Name = FUNCTION(Table[Column]). Ganti SUM dengan COUNT atau AVERAGE dan kamu punya dua measure lagi dalam hitungan menit.

  1. New measure again (right-click Sales ▸ New measure). Type: Order Count = COUNT(Sales[Order ID])

    New measure lagi (klik kanan Sales ▸ New measure). Ketik: Order Count = COUNT(Sales[Order ID])

    Menu path: Right-click Sales ▸ New measure

  2. One more. New measure, then: Average Sale = AVERAGE(Sales[Amount])

    Satu lagi. New measure, lalu: Average Sale = AVERAGE(Sales[Amount])

    Menu path: Right-click Sales ▸ New measure

  3. Add three cards, one for each measure: Total Sales, Order Count, Average Sale. Now you have a headline row.

    Tambah tiga card, satu untuk tiap measure: Total Sales, Order Count, Average Sale. Sekarang kamu punya baris angka utama.

  4. Click a product in your slicer and watch all three cards recalculate at once. That's the power of measures.

    Klik satu produk di slicer-mu dan lihat ketiga card menghitung ulang sekaligus. Itulah kekuatan measure.

✓ Checkpoint — you should now see this

Three cards show a total, a count, and an average. Filtering with the slicer updates all three together.

Tiga card menampilkan total, jumlah, dan rata-rata. Memfilter dengan slicer memperbarui ketiganya bersamaan.

Why this matters / Kenapa ini penting

SUM, COUNT, and AVERAGE cover most of what a beginner dashboard needs. With these three you can already answer "how much, how many, and how big on average" — the questions every manager asks.

SUM, COUNT, dan AVERAGE menutupi sebagian besar kebutuhan dashboard pemula. Dengan tiga ini kamu sudah bisa menjawab "berapa banyak, berapa jumlahnya, dan rata-rata berapa" — pertanyaan yang ditanyakan tiap manajer.

Common mistakes / Kesalahan yang sering terjadi

  • Using COUNT on a column with blanks / Memakai COUNT pada kolom yang ada kosongnya
    COUNT skips blanks. Count an ID column that's always filled so the number is honest. COUNT melewati yang kosong. Hitung kolom ID yang selalu terisi supaya angkanya jujur.
  • Averaging something that shouldn't be averaged / Merata-rata sesuatu yang nggak seharusnya
    Average a value, not an ID. Averaging Order ID gives a meaningless number. Rata-rata sebuah nilai, bukan ID. Merata-rata Order ID memberi angka yang nggak bermakna.
