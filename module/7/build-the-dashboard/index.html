Build the capstone dashboard

In about 40 minutes you will be able to build a complete sales dashboard from a fresh file without step-by-step hand-holding.Dalam sekitar 40 menit kamu bakal bisa membangun dashboard penjualan lengkap dari file baru tanpa dituntun langkah demi langkah.

⏱ 40 minmenit DifficultyTingkat: MediumSedang You need firstButuh dulu: Modules 0 through 6 finished.Modul 0 sampai 6 sudah selesai.
Practice datasetDataset latihan: Capstone superstore A fresh set of sales and product files to prove you can do it alone.Set file penjualan dan produk baru untuk membuktikan kamu bisa sendiri.
⬇ Download dataset

No new skills here — just all your old ones in a row. Each step names the module it came from. Peek back whenever you need to. Take your time.

Nggak ada skill baru di sini — cuma semua skill lamamu berurutan. Tiap langkah menyebut modul asalnya. Lihat lagi kapan pun kamu butuh. Santai saja.

  1. Start fresh: File ▸ New. Then Get data ▸ Text/CSV and load both capstone files. (Module 1)

    Mulai dari awal: File ▸ New. Lalu Get data ▸ Text/CSV dan muat kedua file capstone. (Modul 1)

    Menu path: File ▸ New · Home ▸ Get data ▸ Text/CSV

  2. Open Power Query. Remove blank rows, fix any text-that-should-be-number columns, then Close & Apply. (Module 2)

    Buka Power Query. Hapus baris kosong, perbaiki kolom teks-yang-harusnya-angka, lalu Close & Apply. (Modul 2)

    Menu path: Home ▸ Transform data ▸ Close & Apply

  3. In Model view, make sure a relationship links the two tables on Product ID. Create it if it's missing. (Module 3)

    Di Model view, pastikan relationship menghubungkan kedua tabel lewat Product ID. Buat kalau belum ada. (Modul 3)

    Menu path: Left edge ▸ Model view

  4. Write three measures: Total Sales (SUM), Order Count (COUNT), Average Sale (AVERAGE). (Module 5)

    Tulis tiga measure: Total Sales (SUM), Order Count (COUNT), Average Sale (AVERAGE). (Modul 5)

    Menu path: Right-click table ▸ New measure

  5. In Report view, build: three measure cards across the top, one bar chart of sales by product, and one product slicer. (Module 4)

    Di Report view, bangun: tiga measure card di atas, satu bar chart penjualan per produk, dan satu slicer produk. (Modul 4)

  6. Add a page heading, title your chart, and line the visuals up neatly. (Module 4)

    Tambah judul halaman, beri judul grafikmu, dan rapikan visualnya. (Modul 4)

    Menu path: Insert ▸ Text box

  7. Save the file, then Publish to My workspace. (Module 6)

    Simpan file, lalu Publish ke My workspace. (Modul 6)

    Menu path: File ▸ Save · Home ▸ Publish

✓ Checkpoint — you should now see thisCheckpoint — sekarang kamu harusnya lihat ini

You have a published, tidy dashboard: a heading, three working cards, a titled bar chart, and a slicer that filters the whole page — built by you, start to finish.

Kamu punya dashboard rapi yang sudah dipublikasi: judul, tiga card yang bekerja, bar chart berjudul, dan slicer yang memfilter seluruh halaman — dibuat olehmu, dari awal sampai akhir.

Why this mattersKenapa ini penting

This is what a first day on the job looks like: a blank file, some data, and a dashboard by the afternoon. If you built this, you can do the real thing.

Beginilah rupa hari pertama kerja: file kosong, sedikit data, dan dashboard sebelum sore. Kalau kamu membangun ini, kamu bisa melakukan yang sesungguhnya.

Common mistakesKesalahan yang sering terjadi

  • Skipping the cleaning step because you're excitedMelewati langkah pembersihan karena nggak sabar
    Rushing past Power Query is how totals come out wrong. Clean first, chart second — every time.Terburu-buru melewati Power Query bikin total keluar salah. Bersihkan dulu, grafik kemudian — tiap saat.
  • Forgetting to check the relationshipLupa mengecek relationship
    If your chart shows the same number for every product, the relationship is probably missing. Check Model view.Kalau grafikmu menampilkan angka yang sama untuk tiap produk, relationship-nya kemungkinan hilang. Cek Model view.
